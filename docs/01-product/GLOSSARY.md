# Glossary (canonical terminology)

Canonical term is used in code, API and docs. Aliases are UI labels configurable per tenant/jurisdiction.

| Canonical | Aliases | Definition | Evidence |
|---|---|---|---|
| Tenant | Management company, client org | Customer organisation of the Vertex platform | INFERRED |
| Scheme | Plan, owners corporation (OC), body corporate, strata plan, community title scheme (CTS) | Legal entity of lot owners managed by a strata manager | EV-029, EV-057 |
| Building | Block | Physical building within a scheme | EV-029 |
| Lot | Unit | Individually owned part of a scheme with an entitlement | EV-029 |
| Unit entitlement | Lot liability, contribution schedule | Weight used to apportion levies | INFERRED (statutory norm) |
| Owner | Lot owner | Contact holding an Ownership on a lot | EV-034 |
| Occupier | Tenant (resident), resident | Person living in a lot who is not necessarily an owner | EV-047 |
| Committee member | Strata committee, executive committee | Owner elected to the committee | EV-032 |
| Strata roll | Owners register | Register of lots, owners, addresses | EV-056 |
| Fund | Admin fund, capital works fund (Maintenance/Sinking fund) | Separate pools for levies and expenditure | EV-038 |
| Levy | Contribution | Periodic charge to a lot from the budget | EV-020 |
| Levy schedule | — | Plan of instalments derived from an approved budget | EV-021 |
| Levy run | — | Batch issuance of levy notices for a period | EV-021 |
| Sundry charge | Other charge | Non-levy charge (EV-030) | EV-030 |
| Penalty | Interest | Charge on overdue levies | EV-039 |
| Arrears level | Debtor level | Escalation step in debt recovery | EV-024, EV-025 |
| Debt referral | Collection | Handoff to collection agency | EV-026 |
| Trust account | Scheme bank account | Account holding scheme money | EV-043 |
| Unpresented transaction | — | Transaction recorded but not yet cleared by bank | EV-028 |
| Supplier invoice | Creditor invoice, bill | Invoice from a supplier to a scheme | EV-040 |
| Meeting | AGM, EGM, committee meeting | Formal meeting with agenda, motions, minutes | EV-045 |
| Motion | Resolution | Item voted on | EV-045 |
| Campaign | Comms | Bulk communication | EV-047 |
| Wall | Community wall, committee wall | Notice board | EV-036 |
| Region | — | Grouping of FM properties | EV-093 |
| Property | Site, facility, village, camp, service | FM-managed site | EV-070 |
| Location | Space, floor, room | Node in property hierarchy | EV-075 |
| Asset | Equipment | Maintainable item | EV-072 |
| Maintenance plan | PPM, planned job template | Recurring planned work definition | EV-075 |
| Work Order | Job | Unit of maintenance work | EV-097 (C-06) |
| Service request | Request, ticket, maintenance request | Inbound need from requester | EV-084 |
| Assignment | Dispatch | Allocation of WO to technician/contractor | EV-085 |
| SLA | — | Response/resolution targets | EV-098 |
| Variation | — | Change to scope/cost requiring client approval | EV-090 |
| Compliance record | Licence, insurance certificate, safeguarding check | Supplier credential with expiry | EV-077, EV-078 |
| Ops Centre | — | FM operational dashboard | EV-071 |
| 52-week planner | — | Forward calendar of planned work | EV-075 |
